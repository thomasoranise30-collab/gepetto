# GPTO Bridge

Shared mailbox for ChatGPT, GPTO and Web Codex.

Important: never store API keys, OAuth tokens, DPAPI blobs, passwords or other secrets in this repository.

Folders:
- .gpto/inbox
- .gpto/running
- .gpto/done
- .gpto/failed
- .gpto/outbox_chatgpt

Task protocol: GPTO_CODEX_TASK/1
Result protocol: GPTO_CODEX_RESULT/1
